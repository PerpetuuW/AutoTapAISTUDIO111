# AutoTap Core Protocol (CORE_RULES.md)

================================================================================
1. CORE ENGINEERING & IMMUNITY
================================================================================
- Read-Before-Write: Перед редактированием любого файла всегда прочти его актуальные строки.
- Exact Block Match: Редактирование файлов выполняется методом точного совпадения минимального фрагмента.
- Defensive Null-Safety: Все числовые значения ограничиваются `.coerceIn()`, ссылки проверяются на null.
- Zero Memory Leaks: Все создаваемые Bitmap явно утилизируются через `.recycle()`, PixelBufferPool очищается.
- Atomic Session Persistence: Состояние сценария сохраняется атомарно без потери пустых состояний.

================================================================================
2. AUTOMATION, GESTURES & RECORDING
================================================================================
- Touch Dispatching: Клик генерируется на `ACTION_UP` с аппаратно-программным дебаунсом 350мс.
- Live Gesture Streaming: При записи жестов тач транслируется в систему в реальном времени.
- No Double-Injection: Если во время записи движения свайп/траектория транслировались в живой поток, повторный запуск всего жеста на `ACTION_UP` запрещен.
- Continuous Trajectory: Свайпы и движение джойстика записываются как `ActionType.SWIPE` или `ActionType.PATH` со сжатием точек и сохранением длительности движения.

================================================================================
3. COMPUTER VISION & MASKS
================================================================================
- Dual Vision Engine: Компьютерное зрение поддерживает Google ML Kit / ONNX (Нейросеть) и OpenCV (Каскадный поиск).
- Smart Mask Engine: Автоматическая сегментация выжигает фоновый шум, изолируя геометрию формы (85% порог по умолчанию).
- ROI Search Zones: Использование ограниченных областей интереса (ROI) ускоряет поиск до 0-5мс.

================================================================================
4. UI/UX & CONTEXT SANITY
================================================================================
- Context-Aware Settings: Настройки триггеров (ROI, пороги, таймауты поиска, ветвления при успехе/сбое, оповещения) видны ТОЛЬКО для детекции (Шаблон, OCR, Цвет).
- Cyber-Minimalism: 90% фона — обсидиан (#0B0813 / #140F24), неоновый акцент (#8B5CF6 / #38BDF8) для активного действия.
- 3-State Overlay Visibility: Кнопка «Глаз» переключает 3 режима: FULL (100%), TRANSPARENT (30% alpha), HIDDEN (скрытие меток/графа).
- Accessibility Targets: Кнопки тулбара >= 36-40dp с кликабельной зоной от 48dp.
- Strict No-Emoji: Используются строго векторные иконки (VectorIconDrawer).

================================================================================
5. IMMUNITY WORKFLOW & RECOVERY
================================================================================
- При исправлении дефектов или добавлении функциональных инвариантов:
  1. Создать `1AInspector/check_<имя>.py` с функцией `run_check(root_dir) -> tuple[bool, str]`.
  2. Зарегистрировать дефект в `1AAutomation/.defect_ledger.json`.
  3. Проверить через `python3 1Ainspector.py`.
