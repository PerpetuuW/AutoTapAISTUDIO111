# 1AProtocol: 00. ЯДРО ИНЖЕНЕРНОЙ ДИСЦИПЛИНЫ, ИММУНИТЕТ И ПАТЧИНГ

## 1. ЗАКОН НУЛЕВОЙ ГИПОТЕЗЫ (READ-BEFORE-WRITE)
- Категорически запрещено использовать любые методы, поля, типы и строковые ID, точное присутствие которых не подтверждено синтаксическим чтением непосредственно перед модификацией.
- При любой неопределенности запускается `1Aread.py`. Контекст файла после падений аннулируется и перечитывается.

## 2. СТАНДАРТ ТРАНЗАКЦИОННОГО ПАТЧИНГА (SMART PATCH ENGINE)
- Модификация файлов выполняется по алгоритму:
  1) `Semantic Convergence`: проверка целевого состояния (`ALREADY_SATISFIED`). Падение на уже примененных изменениях недопустимо.
  2) `Whitespace-Trimmed Match`: сопоставление строк с нормализацией `rstrip()` и унификацией `\r\n` ➔ `\n`.
  3) `Anchor-Based Match`: замена по стабильным граничным якорям блока.
- **Git-Native Rollback**: При ошибке любого файла изменения откатываются через Git (`git restore`). Запрещено плодить мусорные копии `.bak`.

## 3. СТРОГИЕ ПРАВИЛА KOTLIN (FQCN & NO REGEX)
- Запрещены слепые многострочные регулярные выражения (`re.sub`) для изменения логики Kotlin.
- **[RULE-FQCN-ENUM]**: Запрещено создавать локальные переменные-алиасы для Enum (`val VT = ...IconType`). Используются только полные имена или импорты уровня файла.
