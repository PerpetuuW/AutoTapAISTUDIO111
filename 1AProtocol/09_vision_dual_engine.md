# VISION DUAL-ENGINE ARCHITECTURE PROTOCOL

### [RULE-VISION-01] СТАНДАРТ ТУМБЛЕРА ДВИЖКОВ
- Переключатель движков обязан строго отображать состояние:
  - При активном OpenCV: `OPENCV ⇄ AI`
  - При активном AI: `AI ⇄ OPENCV`
- Запрещено использовать длинные префиксы ("ДВИЖОК:", "НЕЙРОПОИСК").

### [RULE-VISION-02] ГАРАНТИЯ БЕСШОВНОГО ФОЛБЭКА
- При выборе движка `AI` система обязана автоматически выполнять фолбэк на каскадный алгоритм OpenCV (`TemplateMatchingEngine`), если нейросетевой анализатор не обнаружил текстовых маркеров.
