# UI/UX & GRAPH ERGONOMICS PROTOCOL

### [RULE-STEP-SETTINGS-01] ПРОГРЕССИВНОЕ РАСКРЫТИЕ НАСТРОЕК
- В основном экране `EditActionDialog` отображаются только базовые параметры: Тип шага, Целевой блок (шаблоны/превью) и Базовая пауза шага (`delayMs`).
- Вторичные параметры (длительность удержания, число повторов, разброс px, таймаут поиска, условные переходы) обязаны размещаться внутри сворачиваемого аккордеона `[ ▸ РАСШИРЕННЫЕ НАСТРОЙКИ ]`.

### [RULE-GRAPH-CREATION-02] ДЕТЕРМИНИРОВАННЫЙ СТАРТ ГРАФА
- Запрещено прерывать захват шаблонов навязчивыми модальными окнами создания графа.
- Граф создается строго по явной команде пользователя на основе уже выполненных и настроенных шагов через главное меню или кнопку пульта `onGraphClicked`.

### [RULE-GRAPH-NODE-03] ДОМИНИРУЮЩЕЕ ПРЕВЬЮ ШАБЛОНА
- Для узлов типа `TRIGGER` графическое превью шаблона обязано занимать не менее 50% площади тела карточки узла.
- Палитра добавления узлов в редакторе графа обязана предоставлять кнопку быстрого выбора из библиотеки шаблонов в 1 клик.
