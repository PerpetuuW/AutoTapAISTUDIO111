# 1AProtocol: 02. КОМПЬЮТЕРНОЕ ЗРЕНИЕ, АВТО-МАСКИ И МУЛЬТИПОИСК

## 1. СТАБИЛЬНОСТЬ КАДРА И РЕСУРСЫ
- **Two-Frame VSYNC Flush Barrier**: перед захватом экрана через MediaProjection выдерживается пауза не менее 50мс (сброс 2-3 кадров SurfaceFlinger) после сокрытия оверлеев (`alpha = 0f`).
- **Pre-Touch Snapshot**: снимок выполняется до отрисовки целевым приложением эффекта касания (Ripple).
- **HardwareBuffer Lifecycle**: освобождение аппаратных буферов строго в блоке `finally`: `image.hardwareBuffer?.close()`, `image.close()`.

## 2. АВТОМАТИЧЕСКАЯ ГЕНЕРАЦИЯ МАСКИ (SMART MASK ENGINE)
- При первичном захвате шаблона вызов `SmartMaskEngine.autoOptimizeGlyphSegmentationFast()` выполняется **автоматически в фоне**, рассчитывая оптимальное расширение контура, отступ и порог схожести без необходимости ручного нажатия кнопки «АВТО».

## 3. АДАПТИВНОЕ СЕТОЧНОЕ СКАНИРОВАНИЕ (ADAPTIVE GRID SCAN)
- В мультишаблонном поиске (`TemplateMatchingEngine`) глобальный поиск выполняется по регулярной адаптивной сетке с шагом `coarseStep = min(tw, th) / 2`. Запрещено полагаться на редкие 128 сэмплов Halton на весь экран, приводящие к пропуску целей.

## 4. ИНВЕРТИРОВАННОЕ ОЖИДАНИЕ (WAIT_DISAPPEAR)
- Поддержка `TriggerBehavior.WAIT_DISAPPEAR`: переход по факту исчезновения шаблона (спиннеры загрузки, всплывающие уведомления).
