Детальный технический аудит функций **Записи жестов**, **Компьютерного зрения**, **Калибровки** и **Оптимизаций каскадов** в проекте AutoTap.

## 1. Запись Жестов (`GestureRecorderOverlay.kt` & `PathExecutors.kt`)

| Функция / Модуль | Статус | Детали реализации в коде |
| :--- | :---: | :--- |
| **Живая запись жестов** | ✅ **100%** | Поддерживает клики (`CLICK`), длинные нажатия (`LONG_PRESS`), векторные свайпы (`SWIPE`) и сложные криволинейные траектории (`PATH`). |
| **Сквозной проброс (Passthrough)** | ✅ **100%** | Жест записывается в макрос и **моментально пробрасывается в ОС Android** через `AccessibilityService.performClick()` / `performPath()`. |
| **Временная точность (`timeOffsetMs`)** | ✅ **100%** | Каждая точка `Point2D` сохраняет реальное время физического касания `System.currentTimeMillis() - touchStartTime`. |
| **Человекоподобное сглаживание** | ✅ **100%** | Траектории автоматически сглаживаются сплайнами Catmull-Rom (`PathCompressionEngine.generateSmoothSpline`), устраняя роботоподобные изломы. |
| **Умная запись (ИИ-шаблоны)** | ✅ **100%** | Переключение в режим **УМНАЯ ЗАПИСЬ** на лету: при тапе по экрану ИИ вырезает область, сжимает маску в `SmartMaskEngine` и создает шаги `ActionType.TRIGGER`. |

## 2. Компьютерное Зрение, Поиск и Каскады (`TemplateMatchingEngine.kt`)

| Каскад / Оптимизация | Статус | Описание и показатели |
| :--- | :---: | :--- |
| **L0 Cache** | ✅ **100%** | Кэширование градиентов, квадратов ярких областей и CIELAB LAB-структур в `templateFeatureCache`. Время повторного обращения: `0-1мс`. |
| **L1 Coarse Scan** | ✅ **100%** | Быстрый грубый отсев по адаптивной сетке Найквиста (шаг 2..16px). Оценка яркостного градиента Собеля + CIELAB ΔE цвета. |
| **L2 Fine Scan** | ✅ **100%** | Субпиксельная ZNCC / Собель доводка на выделенных секторах с формированием итогового скоринга. |
| **Расширенный буфер секторов** | ✅ **100%** | Буфер секторов `sectorsToScan` увеличен до **32 секторов** (стандарт) и **64 секторов** (`findAllMatches`). Полностью устранено «голодание» последующих шаблонов в мультипоиске. |
| **OCR мультипоиск** | ✅ **100%** | Запросы вида `"ocr:Текст"` в массиве `multiTemplatePaths` выполняются через ML Kit `OcrEngine` параллельно с графическими масками. |
| **Двойной движок (Dual Engine)** | ✅ **100%** | Переключение на лету между каскадами OpenCV Собель/ΔE и Pure ONNX 1.30.0 16KB-aligned нейросетью (`NeuralVisualMatcher`). |
